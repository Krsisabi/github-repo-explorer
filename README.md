# GitHub Repo Explorer

Поиск по репозиториям GitHub через GraphQL API: список с пагинацией на главной и карточка репозитория с деталями.

Демо: **https://github-repo-explorer-app.vercel.app**

## Стек

React, TypeScript, Redux Toolkit, RTK Query поверх `graphql-request`, типы генерируются из схемы GitHub через `graphql-codegen` (client-preset), сборка на Vite, стили на SCSS-модулях без UI-библиотек, e2e на Cypress.

## Как устроен доступ к API

GitHub GraphQL API требует токен на любой запрос, включая публичные данные. Токен нельзя держать во фронтенде: всё, что попадает в клиентский бандл, публично по определению, и утёкший токен GitHub отзывает.

Поэтому запросы идут через serverless-функцию `api/github.ts`. Токен живёт в переменных окружения на сервере, клиент ходит на `/api/github` и не видит никаких учётных данных. Функция принимает только POST и только те три операции, которые есть в приложении, — иначе прокси стал бы открытым ретранслятором, через который любой желающий тратил бы лимиты нашего токена.

Схема GitHub и сгенерированные из неё типы намеренно не в репозитории: это производные артефакты, которые восстанавливаются командой `npm run prepare:types` — её же выполняют CI и сборка на деплое.

## Запуск

```bash
npm install
npm run prepare:types   # скачать схему GitHub и сгенерировать типы
npm run dev
```

Для работы запросов нужен GitHub-токен в окружении функции: создайте `.env` с `GITHUB_TOKEN=...` и запустите `vercel dev`, чтобы поднялись и фронтенд, и функция. Токену достаточно прав на чтение публичных данных.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Дев-сервер |
| `npm run build` | Проверка типов и продакшен-сборка |
| `npm run lint` | ESLint |
| `npm run typecheck` | Только проверка типов |
| `npm run prepare:types` | Скачать схему и сгенерировать типы |
| `npm run cypress:open` | E2E-тесты в интерактивном режиме |

## Происхождение

Проект начинался как тестовое задание летом 2023 года. В 2026-м обновлён: зависимости переведены на актуальные мажорные версии, доступ к API перенесён за прокси, деплой и CI пересобраны. История коммитов сохранена целиком.
